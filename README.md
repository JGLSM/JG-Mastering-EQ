# JG Designs Mastering EQ

A mastering EQ by JG Designs: a fixed-character input stage, a subtle realtime
Smart EQ and a seven-band passive-style EQ, with LUFS and true-peak metering.

- Product brief and every decision: [`docs/BRIEF.md`](docs/BRIEF.md)
- Installing a Mac build: [`docs/INSTALL-mac.md`](docs/INSTALL-mac.md)
- Notes for Claude Code: [`CLAUDE.md`](CLAUDE.md)

**Status:** prototype. The C13 Ice Grey interface runs inside the plugin and the
controls work, but audio passes through untouched (no DSP yet).

Built with [JUCE](https://juce.com) (Starter licence). Fonts: Archivo and
Michroma, SIL Open Font License (see `ui/fonts/`).
